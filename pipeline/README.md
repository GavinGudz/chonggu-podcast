# 《重估》第 2 期：配图紧凑版的渲染流程

成片顺序：冷开场 → 片头（吴原同口播版，11.8 秒，720p30 放大到 1080p60）→ 正片。
- **停顿：** 压缩 19 处过长停顿，每个剪点 0.1 秒叠化。
- **音量：** 吴原同 -2.4 dB，与顾东政拉平；片头口播 -0.9 dB 对齐正片；整体 -14 LUFS。
- **去齿音：** 只处理吴原同说话的部分（他 4–6 kHz 比顾东政高约 12 dB）。齿音冒头时压 3.5 kHz 以上，最多 8 dB；顾东政的部分逐采样不变。
- **配图：** 叠加 9 张照片，结尾 0.8 秒淡出。照片是动画（animcards.py）：跟着原片元素弹出（放大+显现），框内照片缓慢拉远，图注是照片左下角的米色标签，退场与原片换场同一帧。
  照片尽量放大（右侧 2/3），用 cards.json 的关键帧在不同大小/位置间缓动：标题先完整显示约 1 秒再被盖住；即将出现的标题、方框、气泡、地图连线到来前，照片缩到一边让位。

## 运行（Linux / macOS 都可以）

```bash
pip install imageio-ffmpeg numpy pillow
python3 pipeline/prep.py      # 拼回正片、算停顿剪点和说话人分段（约 5–10 分钟）
python3 pipeline/build.py     # 生成音轨和滤镜图
python3 pipeline/animcards.py # 渲染照片卡片动画到 work/anim/（约 4 分钟，需要 pillow）
bash pipeline/render.sh       # 渲染到 pipeline/out/（约 10–20 分钟）
```

## 期望结果（本机上次跑出的数值，用来核对）
- prep.py：21 处长停顿，剪 19 处，20 段，去掉 407 帧（6.78 秒）；顾东政约 199.7 秒，吴原同约 89.0 秒；冷开场分界约 9.99 秒。
- build.py：TOTAL frames 19117（318.617 秒，新片头 708 帧）。
- render.sh：帧数 19117，响度约 -14.1 LUFS，峰值约 -1.4 dBFS（冷开场、片头、正片各约 -14 LUFS）。
- 2026-09-29 在云端（Linux，ffmpeg 7.0.2）复跑：以上数值全部一致；成片与原片音频互相关偏移为 0，运动帧逐帧对应原片。
- 加去齿音后：吴原同齿音明显的帧（5–10 kHz 比 0.3–4 kHz 还响）从 9.3% 降到 2.7%（顾东政 1.4%）；整体响度只变 -0.02 dB，画面不变。

注：`work/ep_320.gray` 比原片多 1 帧（原片视频首帧 pts=0.021s，导出灰度时首帧被复制了一次），灰度帧号 = 原片帧号 + 1。
它只影响 prep.py 选剪点和判断说话人时的画面分析（偏 1 帧，剪点都落在静止画面里，无实际影响）；渲染按原片真实帧号裁切，音画同步不受影响。

## 素材
- `src/`：片头 `intro_src.mp4`；正片被拆成 `ep_src.mp4.part_*`（GitHub 单文件上限 100 MB），prep.py 会自动拼回并做 sha256 校验。
- `cards/`：已经渲染好的照片卡片（需要 macOS 字体，所以在本机渲染后提交），`cards.json` 是它们的位置和时间。
- `../照片素材/`：原图。1972 年照片来自美国国家档案馆，2026 年照片是白宫官方照片，两者都是公有领域；其余是 Unsplash 图片，可免费商用。
