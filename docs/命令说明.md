# 命令说明

每条命令的输入、输出、门槛和大概用时。用时是第 8 期（16 分钟成片、24 分钟录音、170 句）在一台 18 核 Apple 芯片 Mac 上的数，标「推算」的没有实测。Windows 上都没有实测过。

## 怎么调

```powershell
.venv\Scripts\python -m chonggu <命令> [这一期] [选项]      # Windows（PowerShell）
```

```sh
.venv/bin/python -m chonggu <命令> [这一期] [选项]           # Mac
```

- **这一期**：`episodes/` 下的文件夹名（`ep9`）、一个路径、或期数（`9`、`ep9`、`第9期`）。不写就依次看 `--ep`、环境变量 `CHONGGU_EP`、当前文件夹；`episodes/` 下只有一期就用它（`_template` 不算）。
- 每条命令的全部选项：`python -m chonggu <命令> -h`。
- 只在用到某条命令时才加载它的代码：`doctor`、`new` 不用先装齐听写模型。

退出码：

| 码 | 意思 |
|---|---|
| 0 | 做完了 |
| 1 | 外部程序出错（ffmpeg、node 之类），屏幕上有它最后几行输出 |
| 2 | 门槛没过（「✗ 没过：……」），或者命令、选项写错了 |
| 3 | 缺东西：缺 Python 包、找不到程序、工具包不全。先跑 `doctor` |
| 130 | 按了 Ctrl+C |

## 一览

| 命令 | 做什么 | 门槛（没过就停） | 大概多久 |
|---|---|---|---|
| `new` | 新建一期 | 短名合法；文件夹不重名 | 1 秒 |
| `doctor` | 环境自检（`--install` 装齐） | 有 ✗ 就不过 | 几秒 |
| `fetch-assets` | 下载配乐、音效、字体 | 下载失败或 sha256 对不上 | 几分钟（第一次） |
| `script-check` | 查稿子和 episode.yaml，写估算时间线 | 格式、id、原声登记、章节对得上 | 几秒 |
| `voice` | 录音 → 整条口播 | 重念、静音少字、取段、接缝都没有 open | 约 5 分钟（推算） |
| `check-voice` | 整条口播逐句听写，和字幕比 | `flags.tsv` 没有 open | 2–3 分钟 |
| `timeline` | 按真声重排时间线 | 口播和时间线的句子对得上 | 约 1 分钟（推算） |
| `stills` | 抽几帧看画面 | 页面不报错 | 几十秒 |
| `render` | 一章一章渲，接起来 | 语法、引用、页面错误、每章时长 | 1080p 约 20 分钟，2K 约 24 分钟（推算） |
| `mix` | 混音，出成片 | 配乐编排合规、锚点和素材都找得到 | 约 2 分钟 |
| `qa` | 交付前检查 | 第 9 节清单能自动查的全过 | 几分钟 |
| `pack` | 手机版、编辑包 | 每个手机文件 < 29.5 MiB | 约 4 分钟 |
| `cover` | 封面 16:9 和 3:4 | 有标题、字体齐 | 几秒 |
| `intro` | 标题和发布简介 | 有三个标题和短版简介 | 1 秒 |
| `publish` | 传 GitHub Release（默认空跑） | 传的是 qa 查过的那份；不超 1.95 GB；gh 已登录 | 1080p 约 8 分钟，2K 约 15 分钟 |
| `build` | 从稿子串到打包 | 停在第一个没过的门槛 | 一整轮约 30–50 分钟（推算） |

## new：新建一期

```
new <短名> [--number 期数] [--title 标题] [--host 主讲] [--version v1] [--template 文件夹] [--force]
```

- 从 `episodes/_template/` 复制到 `episodes/<短名>/`，把 `episode.yaml` 头几行填好（期数不写就是已有最大期数 + 1）。
- 写：`episode.yaml`、`script.md`、`music/plan.json`，空文件夹 `assets/`、`voice/`、`out/`、`ch/`。
- 门槛：短名只能用字母、数字、汉字、`- _ .`，不以 `_` 或 `.` 开头；文件夹已经有东西就停（`--force` 照样复制模板文件，不删已有的东西）。

## doctor：环境自检

```
doctor [--json] [--install [--dry-run]]
```

- 查：系统、Python（3.11 以上，建议 3.12）、虚拟环境、Python 包、听写（mlx-whisper / faster-whisper 和模型缓存）、降噪（clearvoice）、ffmpeg（要有 libx264 和 loudnorm）和 ffprobe、变速（rubberband 命令行 → ffmpeg 的 rubberband 滤镜 → audiotsm）、Node.js 22.12 以上、puppeteer 和它的 Chrome、舞台字体、素材缓存、磁盘、内存、git、gh。
- 每项 `✓` 好、`!` 建议、`✗` 必须装、`·` 告诉你一声，后面跟着这台电脑上怎么装。
- `--json`：结果打成 JSON（给 AI 代理读）。`--install`：把缺的装上（Mac 用 Homebrew，Windows 用 winget 和 rubberband 官方 zip），建 `.venv`、装 Python 包、`npm ci`、装 Chrome for Testing、`fetch-assets`，最后再查一遍。`--dry-run` 只打印要做什么。
- 门槛：有 ✗ 就退出码 2。磁盘少于 10 GB 是 ✗、少于 30 GB 是 !；内存少于 16 GB 是 !。

## fetch-assets：下载素材

```
fetch-assets [这一期] [--only 名字,…] [--kind music|sfx|speech] [--from 文件夹] [--pin] [--force] [--list] [--no-fonts]
```

- 读 `assets/manifest.json`（配乐、音效、示例期的录音）和 `stage/fonts/FONTS.json`（开源字体）。
- 写：素材到每个人自己的缓存（Windows `%LOCALAPPDATA%\chonggu\assets`，Mac `~/Library/Caches/chonggu/assets`），字体到 `stage/fonts/`（不进 git）。
- 写了这一期：只下这一期用得到的（配乐编排、音效、录音、原声句）。
- 已经有、sha256 对得上的不再下。没有直链的（manual）列出页面地址，手动下好以后 `--from 下载文件夹`（按文件名里的编号认）。Pixabay 的一律手动（它的条款第 8 条不许程序自动下载、批量复制），自动下载的只有 Freesound CC0 音效、示例期的录音和配乐、字体。
- 两份清单一起读：`assets/manifest.json`（公开）和 `assets/manifest.local.json`（只在本机，不进 git：作品页还没核过授权的先放这里，核过再挪进公开清单）。`--pin`：把新下的文件的 sha256 写回清单（清单要提交）。`--list`：只列出哪些已经有了。
- 门槛：有下载失败或 sha256 对不上的就停。只缺手动下载的只提醒。

## script-check：查稿子

```
script-check <这一期>
```

- 读：`episode.yaml`、`script.md`。
- 先按格式查 `episode.yaml`（类型、必填、取值范围、拼错的键、Windows 文件名不能用的字），每一处错都列出来。
- 再查稿子：有章、章的前缀不重复、每章有句子、`episode.yaml` 的 `chapters` 和稿子的章一致（前缀、章名、顺序）、句子 id 不重复、标了原声的都登记了、登记的原声句稿子里都有、呼吸点的句子都在、新闻插段的章和句子都在。
- 只提醒不拦：画面代码还没写、原声文件还没放、原声没写时长、句子里夹着【】、插段的气口不到 6 秒。
- 写：`timeline_est.json`（每次都重写，每秒 6.1 字估）；`timeline.json` 只在还没有、或者还是估算的时候写。录过音、重排过的不动，只列出稿子和它对不上的句子。

## voice：录音 → 整条口播

```
voice <这一期> [--from 步骤] [--force] [--no-denoise]
```

一共 11 步，每一步的输入没变就跳过（记在 `voice/.stamps.json`）；听写按声音内容缓存，改了一句只重听这一句：

| 步骤 | 做什么 | 写 |
|---|---|---|
| `prep` | 解码成 48 kHz 单声道；切掉 70 Hz 以下；降噪（ClearVoice MossFormer2_SE_48K） | `rec.wav`、`rec_hp.wav`、`rec_se.wav` |
| `asr` | 整条录音听写，带每个字的时刻 | `asr.json` |
| `select` | 每个小句挑最后完整的那一遍 | `sel.json` |
| `assemble` | 拼出原始口播；切点落在真正的停顿上 | `narr_raw.wav`、`narr_spans.json`、`narr_groups.json` |
| `audit` | 每一段头尾找带进来的碎音，带着它、去掉它各听写一遍 | `local.json` |
| `seams` | 判每一截碎音：静掉还是留着 | `seams.json` |
| `chunks` | 按停顿拆段听写，查念了半句又重念的【门槛】 | `chunks.json` |
| `chain` | 人声链：去低频、去齿音、定到 −16 LUFS（不加压缩） | `narr_c_base.wav` |
| `mute` | 碎音原位换成静音，前后逐字比【门槛】 | `narr_c.wav`、`mute_check.json` |
| `lines` | 每句切出来，句中长停顿收到 `pause_cap`，提速（目标 300 字/分，最多 `max_tempo`） | `lines/<句id>.wav`、`lines/pick.json` |
| `narration` | 拼整条口播，加呼吸点和原声句 | `narration.wav`、`narration_quotes.wav`、`narration.spans.json` |

（文件都在 `voice/` 里。）

人要改的三个文件：

- `voice/ovr.json`：某一小句取录音里的哪一段（录音秒数）。`"句id:小句序号": [起, 止]`；`"句id:*": [起, 止]` 整句换；`"句id:*": [[起, 止], [起, 止]]` 几段拼一句；`"句id:k": null` 没念；`["xx", 起, 止]` 两头按字切；`"_edge"` 直接给切点。全部写法见 `chonggu/voice/assemble.py` 开头。
- `voice/seams_review.json`：听过以后的接缝决定：`keep`（自动判静音、要留着的）、`mute`（要静掉的）、`extra`（另外要静掉的一截）。见 `chonggu/voice/seams.py` 开头。
- `voice/flags.tsv`：每一处要人听的地方，一行一处：`status kind id key detail`。听过改 `ok` 或 `fixed`。重跑时同一处的 status 保留。

门槛：

- 录音找不到；`episode.yaml` 没写 `voice.recording`。
- 有小句在录音里没找到：在 `ovr.json` 给出起止或标成没念。
- 原声句没写时长或没有文件。
- 拆段查重（`repeat`）有 open。
- 静音前后逐字比（`mute`）有 open：静掉的是这句自己的字，在 `seams_review.json` 的 `keep` 里留着它。
- 最后：`take`（取段）、`clip`（接缝切到邻句）、`repeat`、`mute` 四类都没有 open。

选项：`--from 步骤` 从这一步起重算；`--force` 全部重算（听写缓存照用）；`--no-denoise` 不降噪（没装 clearvoice 时用；也可以在 `episode.yaml` 写 `voice.denoise: false`）。

## check-voice：整句核对

```
check-voice <这一期> [--only 句id,句id] [--voice 口播.wav]
```

- 读：`voice/narration.wav` 和 `narration.spans.json`。
- 每句单独听写，和字幕逐字比，多字、少字、换字的写进 `voice/flags.tsv`（`kind` 是 `line`），结果在 `voice/check.json`。
- `--only`：只查这几句，别的句子原来的记录留着。
- 门槛：`flags.tsv` 里任何一类还有 open。第 8 期是 26 处，都是听写听错（同音字、人名），一期二十来处是正常的，要人逐条听。

## timeline：按真声重排时间线

```
timeline <这一期> [--voice 口播.wav]
```

- 读：整条口播和它的 `.spans.json`、`timeline.json`。
- 给每个字定真声里的时刻，排章节起止，加呼吸点（呼吸点前镜头先切进来，人声后到：句子里有 `vstart`）。
- 写：`timeline.json`。改之前备份到 `out/timeline_prev.json`；第一次重排时，估算的那条留成 `timeline_est.json`（稿子里写的「停 x」在那里）。
- 门槛：没有口播；口播和 `timeline.json` 的句子对不上（录音以后改过稿子：重跑 voice）。

## stills：抽帧看

```
stills <这一期> [时刻 时刻 …] [--every 秒] [--only 前缀,…] [--h 540] [--out 文件夹] [--stable 8]
```

- 没给时刻：每章抽 3 张（1/4、1/2、3/4 处）。
- 写：`out/stills/s_<秒>.jpg` 和 `log_stills.txt`。几个代理同时抽帧时各用各的 `--out`。
- 抽帧前先逐个文件 `node --check`；引用不对、章还没写只提醒（页面上会显示出错的章）。
- 门槛：页面报错（pageerror、出错、找不到、空档、重叠……），图已经写好了。
- 注意：这是从网页现截的。成片里的半帧和拼接错它看不到，交付前要从成片文件里抽帧看。

## render：渲染

```
render <这一期> [--res 1080|2k] [--only 前缀,…] [--workers N] [--stall 秒] [--no-mux]
```

- 读：`timeline.json`、`ch/*.js`、这一期的 `assets/`、工具包的 `stage/`。先按 `episode.yaml` 生成 `out/stage/index.html`。
- 一次只渲一章（`--stable 8 --tol .002`，2K 加 `--gpumem 8192`），1080p 默认每章 6 路浏览器、2K 5 路。渲到临时文件，查过才换掉旧的。
- 全部章按时间线的顺序接起来（不靠文件名排序），声音一律从混好的 1080p 成片里拿；还没混音就只出无声画面。
- 写：`out/parts/<序号>_<前缀>.mp4` 和日志 `log_<序号>_<前缀>_1080p.txt`（2K 在 `out/parts2k/`）、`out/<版本>_noaudio.mp4`（2K 是 `<版本>_2k_noaudio.mp4`）、`out/cues.json`；有混好的声音时还有成片。
- 门槛（渲之前）：帧率只能是 30；每个 js 文件单独 `node --check`；画面代码引用的句子和字（`cue`、`w`、`c`、`B`、`BE`、`K.cutId`）都在 `timeline.json` 里；每章都有画面代码（`CH.push({name: …})` 和章名对得上）；整个页面搭一遍不报错。
- 门槛（渲的时候）：日志里有 pageerror、出错、找不到、读不到文件、空档、重叠就停；每章长度和时间线差 0.2 秒以上就停；日志 `--stall` 秒（默认 300）没动静算卡死，整组停掉重来一次；接好的整片和时间线差 0.5 秒以上就停。
- `--only`：只渲这几章，渲完照样把全部章接起来（缺章就先不接）。

## mix：混音

```
mix <这一期> [--sample 起秒 止秒] [--no-novo | --novo-only] [--video 无声画面] [--voice 口播.wav]
```

- 读：`music/plan.json`、`timeline.json`、口播、无声画面、`out/cues.json`（画面代码登记的音效和原声）、素材缓存。
- 一次算好配乐、音效、原声，出两份：成片（加口播），和不带口播的版本（给主讲自己剪口播用，音乐照样按口播让开）。说话时音乐切掉 140 Hz 以下；气口里全频段。响度两遍 loudnorm（整体一个增益），−15 LUFS，TP −1.5。有 2K 无声画面就配上同一条声音。
- 写：`out/重估_第N期_<标题>_<版本>_1080p.mp4`、`out/<版本>_novo.mp4`，有 2K 时 `…_2K.mp4`。
- `--sample 起 止`：只出一小段样（`<版本>_混音样_…s.mp4`），新的混音规则先给主讲用手机听。
- 编排格式：`sections` 一段一首 `{file, from, to, offset, under, breath, fin, fout}`；`drops` 撤掉音乐的地方；`hits` 爆点音效；`sfx_keep` 画面登记的音效只留这几类；`sfx_db` 留下的整体再调几 dB。锚点：`END`、`句id`（开口）、`句id.cut`（镜头切点）、`句id.end`（说完）、`句id:字`（第一次出现的那个字），后面可以跟 `+秒` / `-秒`。见 `chonggu/mix/plan.py` 开头。
- 门槛：说话时（`under`）要比人声低 12–20 dB；气口里（`breath`）不能高过 −4 dB；落在章名卡、新闻插段里的那几段要 `breath ≤ −7`、`fin ≥ 1.0`；锚点的句子和字都在；素材文件找得到；有无声画面。不能同时跑两个混音。

## qa：交付前检查

```
qa <这一期> [--only 响度,闪帧,…] [--skip …] [--no-video]
```

- 读：1080p（和 2K，有的话）成片、分章文件和日志、口播、`music/plan.json`、`out/cues.json`、出处清单。
- 画面每个文件只解码一遍，同时喂给几个检查。
- 写：`out/qa/qa_<版本>.txt`（报告），全部跑完而且全过才写 `out/qa/passed.json`（成片的大小和修改时间，publish 拿它核对）。`--only`、`--skip` 只跑一部分时不记为通过。

| 检查 | 过的标准 |
|---|---|
| 时长 | 和 `timeline.json` 差 < 0.2 秒 |
| 大小 | 不超过 `publish.limit_gb`（默认 1.95 GB；2K 超了用 crf 19 重压） |
| 每章时长 | 每个分章文件和时间线差 < 0.2 秒 |
| 渲染日志 | 每章最新的日志里没有 pageerror、出错、找不到、树上没有、空档、重叠 |
| 手机版 | 每个文件 < 29.5 MiB（还没打包就跳过） |
| 响度 | I 在 −15±0.5 LUFS，LRA ≥ 4，峰值 ≤ −1.0 dBFS |
| 没失真 | 两段 60 秒（片子短就取 1/4 长）里，最响的 10% 和最静的 10% 相差 ≥ 15 dB |
| 字速 | 说话时 290–340 汉字/分（原声句不算） |
| 气口 | 口播里两个 ≥ 1.2 秒的空档之间最长 ≤ 40 秒 |
| 配乐编排 | 同 mix 的门槛 |
| 音效连用 | 同一个音效连用 3 次以上（只提醒） |
| 出处清单 | 每个用到的素材在 `assets/manifest.json` 里登记了，或者写进了 `CREDITS_第N期.md` |
| 音轨 | 2K 和 1080p 是同一条声音（哈希一样） |
| 每章有画面 | 每章接近纯色的帧（像素标准差 < 3）不超过 20% |
| 闪帧 | 0 处（`qa.allow` 里放过的不算） |
| 闪烁 / 短镜头 | 0 处（同上） |
| 半帧 | 只和上一次比，多出来的列出来（只提醒；第一次查只记数） |
| 2K 对 1080p | 每章 0 段对不上 |

报告最后一行写着还要人做的：主讲戴耳机用手机从头看完、关键帧从成片里抽出来亲眼看、说「可以发」之后才 `publish --yes`。

单独跑某一个检查（不写报告）：`python -m chonggu.qa.flash 成片.mp4`、`.flicker`、`.glitch`、`.pure`、`.cross_check 2K.mp4 1080p.mp4`、`.lum`。补半帧：`python -m chonggu.qa.fix_spikes <这一期的文件夹> <前缀> [阈值] [--res 1080|2k]`：找出这一章里单帧亮度冒出来又回去的帧，前后各 0.2 秒用 1 路浏览器重渲，干净了才换进分章文件（原片留 `.bak`）。换完要重新接整片、配声音。`render` 会把章重渲一遍（补好的就没了），只接不渲要用 Python 调 `chonggu.render.run` 的 `concat` 和 `mux`（见 `docs/skill/SKILL.md`「渲染」一节；没实测）。

## pack：手机版和编辑包

```
pack <这一期> [--no-parts] [--no-edit] [--no-full]
```

- 读：1080p 成片、不带口播的版本、口播和 `.spans.json`、`timeline.json`。
- 手机版分段：720p，按 `pack.phone_parts` 分组（不写就按章凑，每段不超过 3 分半）。超了 29.5 MiB 就把画质再压一点重出，crf 36 还超就按时长算码率再压。
- 完整手机版：960×540 一整个，小于 29.5 MiB，给主讲戴耳机从头看完。
- 编辑包 `out/编辑包_<版本>/`：逐句口播（和片子里一模一样）和 zip、逐句清单、整条口播（从 0 秒对齐）、没有口播的画面加配乐（1080p / 720p / 手机版）、说明。
- 写：`out/第N期<版本>_手机_<分段>.mp4`、`out/第N期<版本>_完整版_手机.mp4`、`out/编辑包_<版本>/`。
- 门槛：没有成片或不带口播的版本；`phone_parts` 里的章不在时间线里；口播和时间线对不上；有一个手机文件压不到 29.5 MiB 以下。

## cover：封面

```
cover <这一期> [--preview 预览图.png]
```

- 读：`episode.yaml` 的 `cover`（`headline`、`tag`、`big`、`loop`、`sub`、`note`、`evidence`、`credit`、`fonts`），证据底图在这一期的 `assets/`。字体只用随包的开源字体，选好的字体名会打印出来（确认是粗体）。
- 写：`out/重估_第N期_封面_16比9.png`（1920×1080）、`out/重估_第N期_封面_3比4.png`（1080×1440）。`--preview` 另存一张两种并排的。
- 门槛：没有 `cover.headline`；证据图不在这一期的文件夹里；字体找不到。

## intro：标题和发布简介

```
intro <这一期>
```

- 读：`episode.yaml` 的 `intro`（`titles`、`short`、`long`、`source`、`tags`）、`timeline.json`（章节时间戳）。
- 写：`out/发布简介_第N期.md`：短版放最前面（三行加标签，不放时间轴），长版备用（署名、正文、章节时间戳、出处、「以上内容不构成投资建议」）。`#重估播客` 每期都带。
- 门槛：没有三个标题或没有短版简介。

## publish：发布

```
publish <这一期> [--yes]
```

- 默认空跑：读 GitHub 现在的样子，打印会改什么，一个字都不写。主讲看完完整手机版、说了「可以发」之后才加 `--yes`。
- 读：成片（1080p 和 2K）、`out/qa/passed.json`、封面、发布简介、`episode.yaml` 的 `publish`。要先装 gh 并 `gh auth login`。
- 做：成片整个放进 Release（tag 默认 `ep<期数>-<版本>`；文件名 `chonggu_ep<N>_<asset_slug>_<版本>_1080p.mp4`，只用 ASCII，中文名当显示名）；`output` 分支的 `第N期/` 写 README（1080p 和 2K 两个下载）、两张封面、发布简介；根目录 README 的索引里这一期只留一行。都用 `gh api` 写，不 clone 仓库。
- 换文件不用 `--clobber`：先用临时名传新的 → 核对大小和 `state=uploaded` → 删旧的 → 改回原名（下载链接不变）。传到一半断了，再跑同一条命令。
- 门槛（`--yes` 时）：没有 `publish.repo`；Release 文件名不是 ASCII；成片在 qa 之后改过（大小或修改时间和 `passed.json` 不一样）；超过 `limit_gb`；gh 没登录；读不到仓库。

## build：从稿子串到打包

```
build <这一期> [--from 步骤] [--to 步骤] [--res 1080,2k] [--workers N] [--no-denoise] [--force]
```

- 步骤：`script-check` → `voice` → `check-voice` → `timeline` → `render`（`render.res` 的每种各渲一遍）→ `mix` → `qa` → `pack`。
- 每一步就是单独跑那条命令（同样的默认参数、同样的门槛）。一步没过就停，告诉你改好以后 `--from` 哪一步接着跑。
- 不含 `cover`、`intro`、`publish`：封面和简介要人看，上传要人说「可以发」。

## 环境变量

| 变量 | 作用 |
|---|---|
| `CHONGGU_EP` | 默认的这一期 |
| `CHONGGU_CACHE` | 换缓存的位置（素材、模型、rubberband） |
| `CHONGGU_ASR_BACKEND` | `mlx` 或 `faster`：指定听写后端 |
| `CHONGGU_ASR_MODEL` | 换听写模型：faster 写 `large-v3`、`large-v3-turbo`（快几倍，中文略差）或本地文件夹；mlx 写 Hugging Face 仓库名 |
| `CHONGGU_ASR_DEVICE` | `cpu` 或 `cuda` |
| `CHONGGU_ASR_COMPUTE` | `int8`、`float16`、`int8_float16` |
| `CHONGGU_ASR_THREADS` | faster-whisper 在 CPU 上用几个线程（默认核数减 1） |
| `CHONGGU_STRETCH` | `cli`、`ffmpeg` 或 `audiotsm`：指定变速后端 |
| `CHONGGU_CHROME` | 渲染用别的 Chrome（`chrome.exe` 的完整路径） |
| `CHONGGU_FFMPEG` | 指定 ffmpeg（别的外部程序也一样：`CHONGGU_<程序名>`，如 `CHONGGU_FFPROBE`、`CHONGGU_GH`）。所有命令都认它；没设就找 PATH，再找缓存的 `bin/` |
| `CHONGGU_NO_CUDA` | Windows 有 NVIDIA 显卡也不装 CUDA 版 torch |
| `CHONGGU_TORCH_INDEX` | 换 CUDA 版 torch 的下载源 |
| `HF_HOME` | 听写和降噪模型放哪 |
| `HF_ENDPOINT` | 换 Hugging Face 的下载源（国内可以试 `https://hf-mirror.com`） |
| `CHONGGU_NO_REEXEC` | Windows 上不开 UTF-8 模式时，工具包会带 `-X utf8` 重启一次自己；设了它就不重启 |

这些都可以写进工具包根目录的 `chonggu.local.yaml`（一行一个 `名字: 值`，不进 git）：工具包每次启动都读，已经设了的环境变量不盖。在 Windows 上这样最省事，PowerShell、Git Bash（Claude Code）、新开的窗口都一样。

## 输出文件名

全部由 `episode.yaml` 生成（格式可以在 `names` 里改）。例子是第 9 期、标题「英伟达财报」、版本 v1：

|---|---|
