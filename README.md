在 Mac 终端里拼回：

```bash

git clone --depth 1 --single-branch --branch output https://github.com/GavinGudz/chonggu-podcast.git 成片
cd 成片
cat 重估_第3期_注意力与直觉_3比4.mp4.part_* > 重估_第3期_注意力与直觉_3比4.mp4
shasum -a 256 -c 重估_第3期_注意力与直觉_3比4.mp4.sha256
```
