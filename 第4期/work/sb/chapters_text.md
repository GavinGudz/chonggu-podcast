## 14 我的重估  （说话人：吴原同）

- [11.3s] 所以我对于学历的重估是这样的：所谓的对学历祛魅，也不是说不要它，而是学历只是一张门票，它帮你进门，
- [ 3.3s] 在你还没有作品的时候，先让人家先看到一眼。
- [ 7.0s] 就好比如果我没有学历的话，我跟印度的人工智能教授，我还说不上话呢。
- [ 4.1s] 为了拿到它，你也练会了怎么啃下一样更难的东西。
- [ 4.9s] 你先有了这个学历进了门，然后你再通过其他的技能，把你越叠越高。
- [ 6.2s] 但它回答不了两个关键的问题：你到底该往哪边走，还有你学的东西，明天还值不值钱。
- [ 7.2s] 上次我跟顾老师一起讲的那个方向性直觉，有提到一个东西：AI 是工具，所以说方向得人来给。
- [ 2.6s] 学历也是一样，它是工具，不是答案。
- [ 7.5s] 当然我还有一个判断，就是等哪一天，AI 写的东西再也检测不出来，学校考人的方式，那就真的得改了。
- [ 5.3s] 就比如说我刚才还提到，那个 lecture 老师说，我们自己写的代码，它已经完全分辨不出来了。
- [ 3.7s] 到了那天，排名还剩多少分量，我当然也说不准了。
- [ 8.3s] 回头看，我最在乎排名的那一年，其实就是在给我找一个安全感，找一个"你没问题"的东西。
- [ 4.5s] 当然现在我知道，这个安全感其实不是学校给的，而是我们自己做出来的。
- [10.0s] 就是我才大一啊。去年我问，这个学历到底能给我带来什么，所以今年我换了一个问法：除了学历，我还能拿出来些什么东西？
- [10.7s] 当然最后我也想问观众一个问题，就是你现在最在乎的那些技能，最在乎的那些证书，到底是在复利，还是在贬值？我们都可以聊聊。
- [ 2.3s] 这里是《重估》，我是原同，谢谢收听。
