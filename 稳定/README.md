# 《重估：“稳定”》（9:16 竖版）

最新版本：**v2**（2026.10.08），1080×1920 60fps，3:59，-14 LUFS。顾东政的一篇独白：伴侣之间的关系会不会长期稳定？离婚对积蓄意味着什么？为什么想要稳定，为什么 30 岁之前只谈恋爱、不结婚，最后落到「扎根」。

**口播与原稿一字不差**（977 字逐字核对过）；字幕照原稿。

**配音由 AI 根据顾东政本人声音合成**（画面开头和结尾都有标注）：用第 4 期录音里他本人的几段原声做参考，在本地用 F5-TTS 克隆；每句按情绪换参考（反问、激动、怀疑、果断、轻松、坚定、平静），合成后用语音识别逐字核对。发到抖音 / 小红书 / 视频号时请勾选「AI 生成内容」声明。

画面：开场无旁白——金币堆成塔、红色闪电劈下、金币慢动作冲向镜头，再聚成金色的“稳定”。之后镜头跟着走：日落里牵手的两个人 → 戒指碎裂、地面裂开、三个光球升起 → 月夜悬崖和雾海 → 全息曲线图（离婚处劈下闪电、金币散落）→ 一个月一列的金条、塌落 → 黄金时刻的“稳定”和金色台阶、乌云压来 → 裂开的沙漏、倒转的时钟 → 聚光灯下的两张牌、闪电劈中「结婚」→ 银河、罗盘和星座连成的人 → 远山下并肩走的两个人、钢笔画出的路 → 雨夜一步一颗种子 → 地下发光的根、天亮长出的树苗，「扎根」。画面上不再堆说明文字，场景之间用推进和甩镜头衔接。曲线图是假设情境（右上角标注）。配乐和音效全部是合成的，没有用外部素材。
