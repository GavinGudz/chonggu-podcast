## 配音

- 用顾东政第 4 期录音里的真人原声做参考，F5-TTS 在本地零样本克隆，没有上传任何音频。
- 第二版按每句的情绪换参考：问句用他反问的那段（「碰到不会的东西，你愿不愿意搞明白呢？……」），强调的句子用他最激动的那段（「保持饥饿，保持求知欲……」），轻松的句子用他开玩笑的那段（「不是大学，我和吴老师说不定还在哪个平行宇宙才会相遇呢」），还有怀疑、果断、坚定、平静各一段（`voice/refs.json`），几个关键句放慢一点。
- 实测：和只用一段平静参考相比，语调起伏（音高标准差）从 2.4–5.4 半音升到 5.2–7.3 半音（他真实说话约 4.5），声纹相似度不变（0.83–0.93）。
- 也试过 IndexTTS-2.5 的情绪向量：情绪是有了，但和他本人的相似度降到 0.71–0.83、语调反而更平，所以没用。
- 每句合成后用 whisper 按拼音核对：少一个字或多一个字都重来（最多 5 次），保证和文字稿一字不差（同音字不算错，比如「故东正」）。
- 口播和字幕与原稿一字不差（977 字逐字核对）。只在给配音模型的文字里做了读音上的处理：「30 岁」写成「三十岁」，「——」写成逗号，「这个」写成「这各」，「顾东正」按「顾东政」合成（读音相同）。
- 开场没有旁白：金币塔、闪电、金币聚成“稳定”，配乐和音效撑起前 6 秒，然后从原稿第一句开始。


### 参考音频怎么切回来（仓库是公开的，真人原声不入库）

`voice/refs.json` 里每种情绪对应一段，都从第 4 期的 `work/src48.wav` 切：

| 情绪 | 文件 | 原片时间（秒） |
|---|---|---|
| calm（平静） | `voice/ref_b.wav` | 776.45–786.95 |
| question（反问） | `voice/ref_question.wav` | 422.35–429.95 |
| passion（激动） | `voice/ref_passion.wav` | 410.20–420.45 |
| warm（轻松） | `voice/ref_warm.wav` | 625.75–632.30 |
| doubt（怀疑） | `voice/ref_doubt.wav` | 150.15–159.50 |
| firm（果断） | `voice/ref_firm.wav` | 260.15–268.25 |
| resolve（坚定） | `voice/ref_resolve.wav` | 823.60–829.95 |

```bash
cut(){ ffmpeg -v error -y -ss $2 -to $3 -i ../work/src48.wav -af "afade=t=in:d=0.03,areverse,afade=t=in:d=0.08,areverse" -ar 24000 -ac 1 voice/$1.wav; }
cut ref_b 776.45 786.95; cut ref_question 422.35 429.95; cut ref_passion 410.20 420.45; cut ref_warm 625.75 632.30; cut ref_doubt 150.15 159.50; cut ref_firm 260.15 268.25; cut ref_resolve 823.60 829.95
```

- 「这个」在合成时写成同音的「这各」（gè，全调），否则模型把「个」读成很短的轻声、听起来像被吞掉；字幕仍是「这个」。

## 配乐

全部在 `mix.py` 里合成（锯齿波弦乐、拨弦、贝斯、鼓、上升音、重击、雷声、心跳），没有采样。90 BPM 的网格，每一场换一种节奏：开头渐强加心跳 → 金币爆开的重击 → 日落的轻快节拍 → 分开后的低音弦乐 → 曲线图的推进节奏 → 离婚的断音和重击 → 金条重新堆起来 → 台阶的上行 → 两张牌的果断节奏 → 星空的渐进 → 同行的流行节拍 → 沉默时只剩雨声和零星钢琴 → 扎根前的军鼓滚奏和上升音 → 扎根的大和弦。音乐在说话时自动压低 9 dB。

## 重新出片

```bash
cd wending
.venv-tts/bin/python tts.py                     # 配音 -> audio/line_XX.wav、data/timeline.json（只重做改过的句子）
node render.mjs --events data/events.json --w 1080 --h 1920
../.venv/bin/python mix.py                      # 配乐 + 音效 + 口播 -> audio/final.wav
node render.mjs --out out/video.mp4 --w 1080 --h 1920 --fps 60 --workers 8
ffmpeg -y -i out/video.mp4 -i audio/final.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart "out/重估_稳定_9比16.mp4"
./sheet.sh 名字 12,40.5,88      # 抽几帧拼成总览图检查
```

- 改字：`script.json`（每句一行，`gap` 是句后停顿，`tts` 是给合成用的写法，`seed` 换一个数就会重新合成那一句）。
- 改画面：`page/scene.js`，每一帧都是时间 t 的纯函数，所有动作都挂在口播里的某个词上（`at('c5', '少了一截')`）。
- 换成真人录音：把每句录成 `audio/line_XX.wav`（48 kHz 单声道），`data/asr.json` 里对应句子的 key 不变就不会被覆盖。

## 环境

- `.venv-tts`（Python 3.12）：`uv venv --python 3.12 .venv-tts && VIRTUAL_ENV=.venv-tts uv pip install f5-tts mlx-whisper resemblyzer "setuptools<81"`；第一次运行会从 HuggingFace 下 F5-TTS v1（1.3 GB）和 whisper-large-v3-turbo（1.6 GB）。在 M4 上每句约 40 秒。
- `mix.py` 从 `../extras/chonggu_intro/music.py` 导入合成器（钢琴、铺底、低音），和第 4 期同一份。
- 渲染：Chrome（`/Applications/Google Chrome.app`）+ `node_modules/puppeteer-core`，Homebrew 的 ffmpeg。

仓库里没有的：`voice/`（真人参考音频）、`out/`（成片在 `output` 分支的 `稳定/`）、`.venv-tts/`。`audio/line_XX.wav` 是合成好的 40 句口播，留着就不用重新合成。
