## 配音

- 参考音频：第 4 期录音里顾东政的一段 10.5 秒独白（`voice/ref_b.wav`，原片 776.45–786.95 秒：「那么学历给我带来的是机会……还有选择」）。仓库是公开的，这段真人原声没有上传；要重新合成时从第 4 期的 `work/src48.wav` 切出来：

  ```bash
  mkdir -p voice && ffmpeg -ss 776.45 -to 786.95 -i ../work/src48.wav -af "afade=t=in:d=0.03,areverse,afade=t=in:d=0.08,areverse" -ar 24000 -ac 1 voice/ref_b.wav
  ```
- 模型：F5-TTS v1（零样本克隆），本地在 Mac 上跑，没有上传任何音频。
- 每句单独合成，再用 whisper 识别一遍：按拼音比对，错字率超过 8% 就换随机种子重来（同音字不算错，比如「故东正」）。
- 试了四段参考：和他真实声音的声纹相似度 0.84–0.91（他自己另一段真实录音是 0.94，吴原同的声音是 0.64），选了最高也最慢、最像在讲道理的那段。
- 「顾东正」按《重估》一贯的写法改成了「顾东政」；「30 岁」合成时写成「三十岁」，「——」写成逗号，字幕照原稿。

## 重新出片

```bash
cd wending
.venv-tts/bin/python tts.py                     # 配音 -> audio/line_XX.wav、data/timeline.json（只重做改过的句子）
node render.mjs --events data/events.json --w 1080 --h 1920
../.venv/bin/python mix.py                      # 配乐 + 音效 + 口播 -> audio/final.wav
node render.mjs --out out/video.mp4 --w 1080 --h 1920 --fps 60 --workers 8
ffmpeg -y -i out/video.mp4 -i audio/final.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart "out/重估_稳定_9比16.mp4"
./sheet.sh 名字 12,40.5,88      # 抽几帧拼成总览图检查
```

- 改字：`script.json`（每句一行，`gap` 是句后停顿，`tts` 是给合成用的写法，`seed` 换一个数就会重新合成那一句）。
- 改画面：`page/scene.js`，每一帧都是时间 t 的纯函数，所有动作都挂在口播里的某个词上（`at('c5', '少了一截')`）。
- 换成真人录音：把每句录成 `audio/line_XX.wav`（48 kHz 单声道），`data/asr.json` 里对应句子的 key 不变就不会被覆盖。

## 环境

- `.venv-tts`（Python 3.12）：`uv venv --python 3.12 .venv-tts && VIRTUAL_ENV=.venv-tts uv pip install f5-tts mlx-whisper resemblyzer "setuptools<81"`；第一次运行会从 HuggingFace 下 F5-TTS v1（1.3 GB）和 whisper-large-v3-turbo（1.6 GB）。在 M4 上每句约 40 秒。
- `mix.py` 从 `../extras/chonggu_intro/music.py` 导入合成器（钢琴、铺底、低音），和第 4 期同一份。
- 渲染：Chrome（`/Applications/Google Chrome.app`）+ `node_modules/puppeteer-core`，Homebrew 的 ffmpeg。

仓库里没有的：`voice/`（真人参考音频）、`out/`（成片在 `output` 分支的 `稳定/`）、`.venv-tts/`。`audio/line_XX.wav` 是合成好的 40 句口播，留着就不用重新合成。
