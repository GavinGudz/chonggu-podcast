# 《重估》各期总结

整理于 2026-10-08，来源：GitHub `GavinGudz/chonggu-podcast`（`output` 分支各期 README 和发布简介、`ep3` / `ep4` 分支的制作说明、`main` 分支的 `pipeline/`）和本地第 4 期的交接说明。第 2 期的逐字稿不在仓库里，内容只写到主题和配图。

## 节目本身

- 主持：**吴原同**（原同，UNSW 计算机，读过国内中学和马来西亚的大学预科）和 **顾东政**（东政，美国读高中、国外大学读计算机，职高出身，苏州博世实习）。
- 口号：我们重新审视那些被默认接受的答案。每期「重估」一个默认答案。
- 录法：腾讯会议远程录，两人轮流讲各自的一段（基本是独白式，各自 6–8 章），不是你一句我一句。
- 成片结构：冷开场（三句金句，暗色底）→ 片头（「这里是《重估》……今天我们重估 X」，白纸底、红点、名字和音量条）→ 正片章节（顶栏显示「重估 · 第 N 期」、章名和进度刻度）→ 结尾卡「谢谢收听」。
- 视觉：纸白底 + 墨黑 + 一点红（`#c4342c`），宋体大标题、苹方正文；青绿 `#2b5459` 代表顾东政，琥珀 `#b58c46` 代表吴原同。
- 规格：1080×1440 竖版 3:4，60 fps，-14 LUFS。第 2 期的版式是 1920×1080（内容区 x 72–1848、y 150–800，字幕在 840 以下），竖版从第 3 期开始。

## 第 2 期 · 青年交流（2026.09.27 录）

- 成片：配图紧凑版 v4（定稿），5:19，1920×1080 横版 60 fps，-14.1 LUFS；封面有横版和竖版 3:4。在 `output` 分支 `第2期/`。
- 顾东政约 3:20、吴原同约 1:29。主题是青年交流；9 张照片卡片里有 1972 年的机场握手和长城（美国国家档案馆）、2026 年北京机场、白宫南草坪、安德鲁斯基地（白宫官方照片），还有 66 号公路、UNSW 图书馆草坪、机场出发、陆家嘴（Unsplash）。原图在 `main` 分支 `照片素材/`。
- 版本：v1 → v2（吴原同去齿音）→ v3（照片放大，并随画面让位）→ v4（换上吴原同口播的新片头，11.8 秒）。正片标题卡仍写「对谈」，按用户意见不再改。
- 紧凑版的做法（`main` 分支 `pipeline/`，纯 ffmpeg，Linux 也能跑）：在已渲染好的正片上压缩 19 处过长停顿（每个剪点 0.1 秒叠化，共去掉 6.78 秒）、按画面判断说话人、吴原同 -2.4 dB 和顾东政拉平、片头音效 +7 dB，再叠 9 张照片卡片；README 里写了每一步的期望数值，换机器复跑能逐项核对。
- 定下来、后几期沿用的：米色纸面、宋体标题、红色强调、卡拉 OK 字幕、顶部章节时间轴；结尾 D 小调和弦；-14 LUFS。片头三句版的生成参数写在 `chonggu_intro/录音说明.md`（`--lines 3 --p3-speaker wu --p4-speaker wu --total-frames 700`）。

## 第 3 期 · 注意力与直觉（2026.09.29 录）

先剪成一条 7:12 的合并版（8 章），后来按说话人拆成两集，各 4 章，1080×1440 竖版：

**3.1 · 注意力价值（顾东政，3:28）**：该向谁看齐 / 拯救自己 / 一道面试题 / 另一种自由。
从小到大总有人告诉我们该向谁看齐。顾东政讲自己：曾经成绩很差，读过半年职高，后来决定「拯救自己」；升学面试最后一轮被问「有了足够的时间和金钱，你会拿它们做什么」，他的回答是把自己的想法和经历分享出去——也就是现在录这档节目。标题：你的注意力，愿意放在哪里？资料卡引用 Herbert A. Simon 1971 年关于信息过载与注意力的论文。

**3.2 · 方向性直觉（吴原同，3:44）**：方向性直觉 / 浸泡出来的直觉 / AI 的边界 / 比你想象的值钱。
信息不完整、未来不确定时，你已经愿意朝一个方向投入——这不是预测未来，而是「这边值得」的感觉。长期浸泡在一个领域里的人都会留下这种直觉；AI 擅长有边界的事，方向和判断还得交给人。标题：AI 时代，你的直觉值多少？资料卡引用 Kahneman & Klein 2009 年关于直觉专长的论文。

- 拆集的做法（第 4 期照搬）：每集冷开场三句 → 竖版片头 → 正片 → 谢谢收听，结尾互相指向上集 / 下集；顶栏、结尾、封面写 3.1 / 3.2（分镜里的 `label`），片头用 `--label 3.1`；3.2 把章节顺序重排，让单人一集自成一条线。
- 为过审删掉的：美国地标和交易所照片、狗狗币资料卡、医生照片和较长的医生例子（3.2 只留一句，配听诊器图标）、「下注」「变现」「财富自由」的红色强调；章节名「另一种财富自由」改「另一种自由」，画面标题「往一个方向下注」改「往一个方向投入」。台词不改字。话题还避开了「美国」「纽约大学」。
- 识别模型拿不准的字，列成表（成片时间 / 字幕写法 / 备选）放进 README，请人耳确认——这个习惯值得保留。
- 照片：Simon（公共领域）、Kahneman（CC BY-SA 2.0，写明作者、许可和「已裁切调色」）。
- 素材在 `ep3` 分支 `第3期/`：剪辑表 `plan_A/B.json`、分镜 `storyboard34.py`（`EP_VARIANT=A|B`）、`render/`、片头节拍 json。用的还是老的 `assemble.py`（逐句收紧停顿），第 4 期换成了保留原始停顿的 `assemble2.py`。

## 第 4 期 · 学历（2026.10.04 录）

**标题**：学历，到底还值多少？｜重估 第 4 期。合集 19:50（第二版），后来又拆成 4.1（11:38）和 4.2（8:47）。

**顾东政 7 章**：敲门砖 / 人家要的是能力 / 学历承载的期望 / 保持饥饿 / 先去做 / 大学给的朋友 / 机会 · 朋友 · 行动。
第一份实习，领导注意到他是因为「国外大学计算机 + 美国读的高中」，学历是敲门砖；到了第二轮，没人在乎学校，只在乎知识、项目和岗位匹不匹配。在苏州博世，他是部门唯一的实习生、也是当年博世唯一的大一学生，用得上的是适应力、学习心态和抗压能力。职高出身，「不知道做什么也没关系，先去做」。结论三句：学历带来机会，大学带来朋友，学习带来行动。

**吴原同 7 章**：翻聊天记录 / 走廊上的尺子 / 原来成绩是隐私 / 第一学期，AI 来了 / 排名回答不了 / 外部评价 / 我的重估。
录之前翻了自己两年的 AI 聊天记录，发现问了无数次学校排名。从国内走廊上挂出来的成绩（成绩变成把人分成三六九等的尺子），到马来西亚「原来成绩是隐私」，再到 UNSW 第一学期遇见 Codex 和 Claude Code，开始问「我未来的技能是在复利还是在贬值」。结论：学历是一张门票，是工具，不是答案。

**画面**：101 个场景；尺子是贯穿全片的母题，结尾回到片头的「默认 → 重估」。第 4 期给引擎加了尺子、成绩榜（可模糊）、AI 聊天窗、曲线、积木、门、门票、印章、计数、人群（漏斗）、荧光笔、划掉换词；方框先描边后填色；每个场景缓慢推近。

**拆两期**：4.1 / 4.2 各用自己的片头（顶栏「重估 · 4.1」）、冷开场（各自的三句金句）、封面（毕业典礼 / 广州贡院号舍）和结尾卡（预告下集 / 回顾上集）；每期再加 6 张真实新闻截图（只留媒体名、标题、日期，画面注明「媒体 · 日期 / 新闻截图」）。

## 番外 · 模拟退火讲解短片（2026.10.07）

照视频号 trouble1422《年轻时，该不该多折腾？》的形式做的 16:9、58 秒讲解片：三个人用三种走法爬山（只走上坡 / 先闯后收 / 一直折腾），对应贪心、模拟退火、恒温随机游走；12 座随机山 × 每种 4000 人，登顶率 3.9% / 46.7% / 12.1%。口播用 edge-tts 云希，画面是 Canvas 逐帧渲染，配乐用片头的合成器。在 `chonggu-ep4/tuihuo/`，做法见 `short-explainer.md`。
