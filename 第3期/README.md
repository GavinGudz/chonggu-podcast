成片在 `output` 分支（3:4 竖版，1080×1440 60fps）。本目录只放剪辑和渲染用到的素材与脚本，不含原始录屏。

## 剪辑

- `剪辑/plan_v1.json`：最终剪辑表（录屏里的起止秒数 + 字幕原文），106 段。三个剪辑方案（紧凑 / 故事 / 钩子）经一个评审合并，再用识别模型逐处打分核对。
- 听不清的地方不写猜测的字：「Meme 币 / 哈基米」那段没用原话，改用资料卡（狗狗币 2013 年作为玩笑诞生）。
- 口误和重复在词级别剪掉（例如「从小学到高到初中」→「从小学到初中」、「连这个，连这个梗」→「连这个梗」）。

## 画面

- `render/`：网页排版，每帧由 `renderFrame(t)` 画出，`render.mjs` 用多个无头 Chrome 并行截图后编码，约每秒 90 帧。
- `scripts/storyboard34.py`：分镜，所有元素按台词短语对时。
- 版式沿用第 2 期：米色纸面、宋体标题、红色强调、卡拉 OK 字幕、顶部章节时间轴。

## 声音

整体 -14 LUFS，峰值 -1.5 dBFS。片头用片头生成器自己的母带；结尾是合成的 D 小调和弦（与第 2 期结尾同调）。
